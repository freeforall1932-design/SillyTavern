Updating SillyTavern on Windows
===============================

Git installation
----------------
If you installed this copy with `git clone`, double-click `UpdateAndStart.bat`.
It pulls the newest files, refreshes production dependencies, and starts
SillyTavern. Git for Windows must be installed.

Downloaded archive
------------------
1. Download and fully extract the newer archive into a new writable folder.
2. Copy `data` from your old folder into the new folder.
3. Start the new copy with `Start.bat`.
4. Check that your content is present before deleting the old folder.

Never copy the full `public` folder from an old version. Your personal content
is stored under `data`.
